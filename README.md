# Tools

一个纯前端小工具集合，全部单文件 HTML，浏览器打开即用，无需安装任何依赖。

## 工具列表

| 工具 | 说明 | 文件 |
|---|---|---|
| 全年一次性奖金模拟测算 | 比较并入工资与单独计税哪种更省税，支持比例/手动双模式、跨月奖金单选方案对比 | [tax-calc.html](tax-calc.html) |
| 职业体验模拟器 PRO | 沉浸式体验 40+ 种职业的一天，AI 驱动的事件分支与决策，探索不同人生 | [career-sim.html](career-sim.html) |
| 考公考编面试真题与案例库 | 收录各地事业单位/公务员面试真题，配套政策案例与答题模板，支持地区/年份/题型多维筛选 | [interview-materials.html](interview-materials.html) |

## 使用方式

直接在浏览器中打开对应 HTML 文件即可，所有工具均为零依赖单文件应用。

也可通过 GitHub Pages 在线访问：

- https://suu-xii.github.io/tools/tax-calc.html
- https://suu-xii.github.io/tools/career-sim.html
- https://suu-xii.github.io/tools/interview-materials.html

## 技术特点

- 纯 HTML / CSS / JavaScript，零外部依赖
- 单文件架构，便于部署和分享
- 响应式设计，适配桌面和移动端
